## Production indexing and measurement

- Set NEXT_PUBLIC_SITE_URL to the confirmed public HTTPS origin before building. SITE_URL remains the origin for form security and private delivery links; both should agree in production. The current localhost setting must never become a search canonical.
- Deploy, verify the domain in Google Search Console, submit /sitemap.xml, inspect key URLs and run Google's Rich Results Test on the public homepage. External account/domain verification remains pending.
- Track search queries, impressions, clicks and enquiry conversions by landing page once real data is available. Review technical indexing first, then refine copy around relevant observed queries. No analytics cookies or credentials were added.
- Keep the event details current. Replace the clearly labelled 2023 archive with an approved 2027 brochure when available. Never invent current rates or admission terms.
- Earn editorial references through useful, accurate event information. Do not buy ranking links, automate directory spam or promise first-page rankings.
